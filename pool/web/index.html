Окно PPLNS и риски
Награда найденного блока делится по последней принятой работе. Сложность каждой шары учитывается: количество лёгких CPU-шар нельзя сравнивать с количеством GPU-шар напрямую. Граничная шара учитывается частично.
Окно равно двум ожидаемым объёмам работы на блок при текущей сложности сети. Пока окно заполняется, награда распределяется по имеющейся работе. После отключения ваша работа остаётся в окне, пока её не вытеснят новые шары. Заполнение: —.
Награда появляется только после найденного пулом блока. Шары и текущая доля не гарантируют доход. Блок вне основной цепи не оплачивается. При рассинхроне или неопределённом результате перевода выплаты приостанавливаются для проверки.
Пул хранит награды на кошельке оператора до выплаты участникам. Ни созревание в 100 блоков, ни проверки не исключают глубокую реорганизацию сети.

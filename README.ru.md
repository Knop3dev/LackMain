# lackminer LBTC

CPU и OpenCL-майнер для [Late Bitcoiners](https://latebitcoiners.com/). SOLO, официальный HTTPS-пул, отдельный GUI и локальная веб-панель.

[English](README.md) · [Скачать](https://github.com/Knop3dev/LackMain/releases/tag/lbtc-v0.1.0)

## Запуск

**Windows:** распакуйте архив и откройте `lackminer-lbtc-gui.exe`. Укажите свой адрес LBTC, режим SOLO или Pool и нужные устройства. Сохраните настройки. Для SOLO разблокируйте свой кошелёк локально; для пула достаточно публичного адреса. Нажмите «Начать майнинг».

**Linux:** распакуйте архив, выполните `chmod +x lackminer-lbtc lackminer-lbtc-gui` и запустите GUI или консольную версию.

**macOS:** выберите архив Intel или Apple Silicon. Приложение не подписано сертификатом Apple; разрешение запуска может потребоваться в настройках безопасности. GPU доступен при наличии рабочего OpenCL; CPU не требует OpenCL. Управление частотами и питанием в macOS недоступно.

## Команды

```sh
lackminer-lbtc --list-devices
lackminer-lbtc --mode pool --address YOUR_LBTC_ADDRESS --devices all
lackminer-lbtc --mode solo --address YOUR_LBTC_ADDRESS --devices 0,1 --key-prompt
lackminer-lbtc --mode pool --address YOUR_LBTC_ADDRESS --no-gpu --cpu-workers 4
lackminer-lbtc --panel
```

Замените `YOUR_LBTC_ADDRESS` своим адресом. Вместо `--key-prompt` можно указать `--wallet /путь/к/wallet.json`: пароль будет запрошен отдельно. Ключ и пароль не передаются аргументами командной строки и не сохраняются майнером. После перезапуска потребуется повторная разблокировка.

Параметр `--cpu-workers` добавляет CPU к выбранным GPU. Диапазоны nonce не пересекаются, результаты проверяются одной эталонной реализацией. Дополнительной комиссии майнера нет.

Панель: `http://127.0.0.1:8808`. Майнинг запускается кнопкой. `--panel --start` запускает настроенный пул вместе с панелью. Не публикуйте этот порт в Интернет; для удалённого доступа используйте SSH-туннель.

## Настройки видеокарты

По умолчанию майнер **не меняет настройки драйвера**. Пустые поля сохраняют текущие параметры. Сохранённый разгон не применяется при запуске: нужна отдельная кнопка или `--apply-tuning`.

| Параметр | Назначение |
| --- | --- |
| `--devices 0,1` или `all` | Выбор GPU |
| `--intensity 80` | Интенсивность 1–100% |
| `--worksize 128` | Рабочая группа 32, 64, 128 или 256 |
| `--batch 1048576` | Число nonce на запуск ядра |
| `--power-w 120` | Лимит драйвера NVIDIA/Linux; где недоступен — пауза по показаниям потребления |
| `--power-percent -10` | Изменение лимита питания AMD Windows в процентах |
| `--core-mhz ЗНАЧЕНИЕ` | Частота ядра |
| `--memory-mhz ЗНАЧЕНИЕ` | Частота памяти |
| `--max-temperature 80` | Пауза при температуре GPU, если датчик доступен |
| `--max-hotspot 85` | Пауза при hotspot, если датчик доступен |

AMD Windows использует официальный ADLX SDK, NVIDIA — `nvidia-smi`, AMD Linux — sysfs. Неподдерживаемая настройка вызывает ошибку. Могут потребоваться права администратора. Напряжение не изменяется. Единицы частоты памяти зависят от драйвера. Восстановление возвращает NVIDIA к управлению частотами драйвером, AMD — к сохранённым параметрам. Программная пауза по потреблению не заменяет аппаратный лимит мощности. Недоступные датчики не подменяются выдуманными значениями.

Нет списка разрешённых моделей: используются устройства OpenCL 1.2, найденные в системе. Для AMD/NVIDIA нужен OpenCL-драйвер производителя; Intel и Apple могут также появиться в списке. До майнинга проверяются совпадение CPU/GPU и сравнение target. Перечисление устройства не гарантирует компиляцию ядра его драйвером. Остальное оборудование требует проверки на самом устройстве.

## SOLO и пул

В SOLO награда идёт на указанный адрес с обязательной выплатой основателю по текущей политике ноды. Подпись создаётся локально, отправка — по HTTPS.

Пул использует официальный API v67: `/api/pool/info` и `/api/pool/share`. Пул предоставляет адрес наград и сложность shares; адрес участника включается в memo coinbase. Учёт, подпись блоков и выплаты выполняет пул. Проверка и вывод — на [странице пула](https://latebitcoiners.com/pool/). Stratum не используется. Для подключения нужны доступные официальные API.

Правила времени и допуска ноды соблюдаются. Готовое решение ждёт разрешённого времени отправки; текущий хешрейт в этот момент равен нулю. Большая скорость не гарантирует каждый блок. Решение SOLO сохраняется при перезапуске и проверяется относительно актуального родительского блока. Автовосстановление ограничено тремя попытками за десять минут.

## Hive OS

Flight Sheet с Custom miner:

| Поле | Значение |
| --- | --- |
| Miner name | `lackminer-lbtc` |
| Installation URL | `https://github.com/Knop3dev/LackMain/releases/download/lbtc-v0.1.0/lackminer-lbtc-0.1.0-hiveos.tar.gz` |
| Wallet template | Ваш адрес LBTC |
| Pool URL | Пусто |
| Extra config | `pool` или `solo` |

Пул запускает все найденные GPU. Частотами управляет Hive OS; майнер сам разгон не применяет. Для SOLO разблокируйте кошелёк через панель, пробросив порт: `ssh -L 8808:127.0.0.1:8808 user@rig`. Откройте `http://127.0.0.1:8808`. После перезапуска фермы потребуется разблокировка. Не добавляйте ключ в Flight Sheet.

Нужны glibc 2.31 или новее и совместимый OpenCL-драйвер.

## Сборка

Python 3.12+, установка: `pip install -r requirements.txt pyinstaller==6.16.0`. Тесты: `python -m unittest discover -s tests -v`.

Для Windows сначала соберите AMD helper: `cmake -S native -B build/native`, затем `cmake --build build/native --config Release`. Пакет: `python tools/package.py`. Для сборки Linux GUI нужен Tk. GitHub Actions собирает Windows x64, Linux x64 и оба варианта macOS.

`--self-test` проверяет GPU-драйвер. `--benchmark --seconds 30` измеряет настоящий перебор nonce и CPU reference на синтетическом задании без отправки в сеть.

Рабочие данные находятся в каталоге данных приложения текущего пользователя. Другой файл настроек: `--config FILE`.

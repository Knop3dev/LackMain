CPU and OpenCL miner for Late Bitcoiners.

- SOLO and official HTTPS pool protocol.
- Multi-GPU selection, CPU workers, Windows GUI and local web panel.
- Driver settings stay unchanged on startup; tuning requires explicit application.
- Windows x64, Linux x64, macOS Intel/Apple Silicon and Hive OS packages.

Preview release. Hardware validation is available for RX 6700 XT on Windows. Other GPUs and operating systems require on-device verification; startup checks the installed GPU backend. Pool connectivity depends on official API availability.
